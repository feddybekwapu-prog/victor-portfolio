## One-time setup
1. Upload every file and folder from this package to the main branch of the repository, including the hidden `.github` folder.
2. In the repository, open Settings > Pages and set Source to "GitHub Actions".
3. Wait about two minutes for the first publish (see the Actions tab).
4. Create a fine-grained access token: GitHub > Settings > Developer settings > Personal access tokens > Fine-grained tokens. Limit it to this repository and give it "Contents: Read and write".
5. Open the dashboard address, choose "Sign in with token", and paste the token.

## Adding work later
Open the dashboard, choose Projects or Blog posts, tap New, fill in the form, and Publish. The site updates in about a minute.

## Before going public
Replace everything labelled "Sample" and the placeholder email, LinkedIn, and WhatsApp details.
